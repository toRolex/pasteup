深夜拼贴桌 · NIGHT DESK

how it was built — 台灯下的构建记录

收到的 brief

把 pasteup 场景放到深夜咖啡馆的一张小桌：桌面深木色，一盏暖台灯打出一圈光锥，纸片在光里发亮、在暗处沉静，界面是暗色但绝不刺眼。暗色光照叙事能力轴：暗色光照叙事（6 方向唯一深色）

要 prove 的一件事：暗色 ≠ 刺眼，反而更能烘托纸质感。台灯光锥内的纸片像被真实照亮，「纸感」由光照方向而非材质堆砌达成。

签名技法

  • 径向光锥 overlay：mix-blend-mode: screen 暖光径向渐变照明层 + 6.5s 自定义缓动「呼吸」。
  • 纸片光照响应：每张纸片按与光源距离经 smoothstep 算出 --lit，实时合成 brightness + 贴形 drop-shadow 暖光；拖拽纸片进出光锥实时亮/暗。
  • 暗色对比布局：深夜桌 #2B241C 底 + 台灯暖光 #FFD28A 高对比叙事。
  • 台灯开关微交互：顶栏开关 + 点击画布灯头；关灯光锥淡出、灯头垂下、纸片沉入夜色。
  • 柔边投影：drop-shadow(0 18px 16px rgba(0,0,0,.55)) 宽模糊落影贴合纸片形状。
  • 程序纹理与资产：纸片纹理 = SVG feTurbulence 噪点；夜景照片 = canvas 运行时生成（夜空/星/月/远山/湖面反光）。
  • 桌面杂物 marginalia：铅笔 + 咖啡渍 + 两枚 Caveat 手写便利贴。

真实代码摘录

// smoothstep：光随纸片到光源距离平滑衰减
const d = dist(piece, lampCenter) / maxR;
const t = clamp(d, 0, 1);
let lit = t * t * (3 - 2 * t);        // smoothstep 缓动
lit = 1 - lit;                          // 近光则亮
if (!lampOn) lit *= 0.32;               // 关灯沉入夜色
p.style.setProperty("--lit", lit.toFixed(3));

批判循环发现与改动

  • 信息架构严格不动：顶栏 56px + 左栏 260px（工具+图层）+ 中画布 + 右栏 280px（色板/纹理/属性）。
  • 光照响应引擎对齐光锥落点：光源取径向渐变最亮带（0.36 × 画布高），与纸片中心同坐标系，保证「灯下的叶最亮、光缘的月次之、暗处沉」。
  • 滑块真实驱动：右栏旋转/透明度/明度滑块与画布联动，是「活界面」不是死样机。
  • 对比度实测：面板标题 4.9:1、次级文字 5.6:1、主文字 10.1:1；票据手写字加深墨色、票纸提亮至 #C08A4E 满足 4.5:1。
