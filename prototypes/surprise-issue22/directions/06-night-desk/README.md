# 06 深夜拼贴桌 NIGHT DESK

**概念一句话**：把 pasteup 场景放进深夜咖啡馆的一张小桌——深木桌面、一盏暖台灯的光锥，纸片在光里发亮、在暗处沉静；界面是暗色，但绝不刺眼。

## 要证明的一件事

暗色 ≠ 刺眼，反而更能烘托纸质感。台灯光锥内的纸片像被真实照亮——「纸感」由**光照方向**而非材质堆砌达成；这也是 6 个方向里唯一的深色方向，覆盖暗色能力轴。

验证：光锥最亮带 L≈157 → 灯下的枫叶纸片 L≈142（主角）→ 光缘的月 L≈107 → 暗处的票据 L≈68 → 最深暗的宝丽来照片 L≈19；关灯后枫叶从 L≈142 骤降到 L≈47，界面其余部分（顶栏/左右栏）保持可读。

## 技法清单（≥3）

- **径向光锥 overlay**：`mix-blend-mode: screen` 的暖光径向渐变作为照明层（brief 允许的照明用途），带 6.5s 自定义缓动「呼吸」。
- **纸片光照响应**：每张纸片按与光源的距离经 smoothstep 缓动算出 `--lit`，实时合成 `brightness + 贴形 drop-shadow 暖光`；**拖拽纸片进出光锥会实时变亮/变暗**（直接证明「光照方向」）。
- **暗色对比布局**：深夜桌 `#2B241C` 底 + 台灯暖光 `#FFD28A` 高对比叙事；正文对比度实测 ≥4.5:1（见「可访问性」）。
- **台灯开关微交互**：顶栏开关 + 点击画布灯头均可开关；关灯时光锥淡出、灯头垂下、纸片沉入夜色，全程自定义 easing。
- **纸片在暗色上的柔边投影**：`drop-shadow(0 18px 16px rgba(0,0,0,.55))` 的宽模糊落影，贴合纸片形状。
- **自定义 easing**：`cubic-bezier(.16,1,.3,1)` / `(.22,1,.36,1)` / `(.65,0,.35,1)` / `(.45,0,.55,1)`，无裸 `linear`。
- **程序纹理与资产**：纸片纹理 = SVG `feTurbulence` 噪点（非渐变糊弄）；夜景照片 = canvas 运行时生成（夜空/星/月/远山/湖面反光）。
- **桌面杂物 marginalia**：铅笔 + 咖啡渍 + 两枚 Caveat 手写便利贴（「光下的旧纸最好看」）。

## 关键构建决策

- **信息架构严格不动**：顶栏 56px + 左栏 260px（工具+图层）+ 中画布 + 右栏 280px（色板/纹理/属性）。
- **光照响应引擎对齐光锥落点**：光源取径向渐变的最亮带（`0.36 × 画布高`），与纸片中心同坐标系，保证「灯下的叶最亮、光缘的月次之、暗处沉」。
- **旋转/透明度/明度滑块真实驱动纸片**：右栏属性面板与画布联动，是「活界面」不是死样机。
- **文字对比度实测**：面板标题 `#AD8F63`（4.9:1）、次级文字 `#B49A6F`（5.6:1）、主文字 `#E8D5B0`（10.1:1）、亮底深字 `#2B241C` on `#FFD28A`（10.8:1）；票据手写字加深墨色、票纸提亮至 `#C08A4E` 以满足 4.5:1。
- **响应式**：≥861px 固定高 app 禁页面滚动；≤860px 折叠为 顶栏/画布/左栏/右栏 纵向流（390px 不塌），并隐藏一枚便利贴、缩小台灯与纸片避免叠压（叠压已用几何检测清零）。
- **可访问性**：语义化 HTML、`role="switch"`、`aria-checked`/`aria-pressed`、`aria-live` 状态播报、`prefers-reduced-motion` 关闭呼吸/选框动画。
