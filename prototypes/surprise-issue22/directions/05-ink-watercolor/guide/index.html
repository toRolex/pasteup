墨与水彩

INK & WATERCOLOR · 湿纸上的构建记录

收到的 brief

把 pasteup 做成一张湿润的水彩纸：纸片边缘有水彩晕染、墨色往纸里渗开，选中时颜色像刚滴上去还在流动，整个界面是水彩色卡+滴管+留白的画室。水彩液体渲染能力轴：水彩液体渲染

要 prove 的一件事：水彩的边缘是活的——纸片不是硬边多边形而是「墨往纸里渗」的湿边缘，换色时像重新滴了一滴颜料，证明程序化水彩质感可达。

签名技法

  • canvas 水彩晕染算法（手写，非贴图）：形状边缘沿法线随机偏移 120+ 采样点 + softCircle 径向羽化；边缘内侧叠 darken(color,30) 浓色积线复刻「颜料在纸边积住」；点内 240 个纤维噪点 + 3 层湿度 wash；湿/干两态。
  • SVG filter 湿边羽化：#wet-edge 只位移 alpha 通道（feColorMatrix 提取 alpha → feDisplacementMap → feGaussianBlur → feComposite in），颜色原位，不产生透明黑边。
  • 滴管取色动画：取样涟漪 ring + 色板/HEX 同步。
  • 颜色流动缓动：4 条自定义 cubic-bezier + rAF 滴入插值，teardrop 沿曲线滴落、溅水珠 + 涟漪，undo 可退回。
  • 留白构图：画布左上大留白 + 两处批注（「水未干，慢慢来。」「let the paper breathe」）。

真实代码摘录

// 边缘色积线：在形状内缘叠深色，复刻水彩"颜料在纸边积住"
const edgeDark = darken(color, 30);
for (let i = 0; i < 120; i++) {
  const a = rnd() * Math.PI * 2;
  const bx = x + Math.cos(a) * R * (0.86 + rnd() * 0.1);
  const by = y + Math.sin(a) * R * (0.86 + rnd() * 0.1);
  softCircle(ctx, bx, by, R * 0.10, edgeDark, 0.5 + rnd() * 0.4);
}

批判循环发现与改动

  • 纸片画布留余白：形状只占画布中央 66%（SHAPE_SCALE），四周留给晕染渗出，否则 canvas 裁掉湿边。
  • 最大坑：ring 的 fill 默认黑块：非选中纸片的 .ring SVG 若不加 opacity:0; fill:none; position:absolute，circle 落 SVG UA 默认 fill:black，渲染成巨大黑块。
  • SVG 滤镜只动 alpha：直接位移透明 canvas 会在边缘取样到透明黑产生暗晕，改 alpha-only + feComposite in 保留原色。
  • 对比度：--ink-faint 调至 #756B5D（4.79:1）。

验证结果

console errors：0（shot.js 复跑）。prove 断言（量化）：audit 量出三张纸片 halo 58/69/34px；像素采样见深色积线 (196,95,85) 与叶身 (235,202,193) 分层；放大远山右缘见 10+ 列羽化斜坡而非 1 列硬切。
