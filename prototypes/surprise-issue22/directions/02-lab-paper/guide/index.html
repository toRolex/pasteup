how it was built — 纸张实验室构建记录

收到的 brief

把 6 种程序纹理（褶皱 / 水彩晕染 / 颗粒 / 织物拉丝 / 大理石纹 / 纤维）做成活的：每个纹理磁贴和纸片填充都用 canvas 实时生成、seed 随机，界面是一间"纸张实验室"。canvas 程序纹理能力轴：canvas 程序纹理

要 prove 的一件事：6 种纹理全部程序化实时生成且"结构随机、颜色稳定"——同一纹理换 seed 结构就变，但换颜色纹理不串色。直接证明 issue #22 的 wayfinder #9/#10 决策在视觉上成立。

签名技法

  • 手写 Value Noise + fBm：6 个生成器共享确定性噪声基元 hash2 → valueNoise → fbm，签名 (seed, style, scale) → 灰度明度层，与颜色解耦。
  • seed 驱动随机 + 结构哈希（ST）：luma 经 FNV 哈希折叠成 4 位 hex「ST 结构哈希」，与「CH 色值」分开展示。
  • 每纸片独立 re-seed：seed 刷新按钮 / 全部重取样 / 双击画布空白取样新纸片。
  • 纹理缩放 50–200% + 旋转 90° 实时重合成（防抖 70ms）。
  • 数值读数动效：monoJump tick + odometer 式 rollValue 逐字符级联。
  • 对照实验便签：同一 seed、两色并排渲染，ST 哈希一致，直观证明色/结构解耦。
  • 实验室叙事：坐标纸底、描摹叶线幽灵、光标读数、norm L 光值、ms/帧 合成耗时、连点 5 次触发"实验室自检"彩蛋。

真实代码摘录

// 确定性噪声基元：同一 (seed, x, y) 永远返回同一值
function hash2(x, y, seed) {
  const h = (Math.sin(x * 127.1 + y * 311.7 + seed * 74.7) * 43758.5453);
  return h - Math.floor(h);
}
function fbm(x, y, seed, oct = 4, lac = 2, gain = 0.5) {
  let sum = 0, amp = 0.5, f = 1;
  for (let i = 0; i < oct; i++) {
    sum += valueNoise(x * f, y * f, seed + i * 1013) * amp;
    f *= lac; amp *= gain;
  }
  return sum;
}

批判循环发现与改动

  • 颜色稳定 = 架构保证：生成器只输出灰度 luma，上色在最后一步 luma × 色 完成。换色必然不改变结构，这是架构保证而非 UI 技巧。
  • 画布尺寸策略：纸片按 w·dpr（封顶 1.5）生成，luma 按参数 key 缓存（LRU 26 项），滑块只重算受影响纸片。
  • 移动端 fit 缩放：内容坐标系固定 900×770，按 min(planeW/900, planeH/770) 自适应，390px 不塌。
  • 对比度：正文墨褐 7.3:1、辅助 mono 5.6:1、主按钮深苔绿白字 4.8:1。

验证结果

console errors：0（desktop/mobile 双视口 harness 实测）。prove 断言：换色时 ST 1AB8 不变、CH 变；重取样 ST→BFAA；对照实验同 seed 异色均 ST 0xBF27。结构随机、颜色稳定成立。
