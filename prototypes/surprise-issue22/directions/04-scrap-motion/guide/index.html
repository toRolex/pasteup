how it was built — 纸屑的运动记录

收到的 brief

纸片的生命由碎纸粒子构成：选中、拖动、删除纸片时它解构成碎纸屑再重组，图层重排时纸片像被风掀起翻面，界面充满纸张的物理运动。粒子物理能力轴：粒子物理

要 prove 的一件事：拼贴过程本身的「运动美感」——纸片不是静态粘贴，而是有拆解、飘动、重组的过程，让用户感觉到纸张的物理存在。

签名技法

  • 手写 canvas 粒子系统（requestAnimationFrame，无粒子库）：解构时按颜色组散成 30 枚不规则碎纸屑（四边抖动形状、自旋、重力、地面/墙面弹性回弹），重组时 spring 收敛。
  • 物理弹跳 / 重力：free 粒子带 gravity / restitution / friction，可在地面墙面弹跳。
  • 拖拽解构 → 跟随 → 重组：拖起纸片 → 纸屑云保留轮廓跟随指针，拖动甩出拖尾，松开飞回拼合。
  • 纸屑撒落：演示动效 / 导出 / 品牌彩蛋从画布顶撒落彩色纸屑。
  • 图层风掀翻面：重排时纸片 scaleX 翻折 + 上抬 + 弹性落位 + 溅出碎屑。
  • gsap 时间线 + CustomEase：scrapOut / scrapIn / wind / scrapBounce 四套缓动驱动演示。
  • 程序化纸纹：皱纹/水彩/瓦楞/金葱四种 dataURL，SVG pattern 覆盖纸片。

批判循环发现与改动

  • 纸片 = DOM + 粒子 canvas overlay：纸片本体是带 torn-edge SVG filter 的 DOM，粒子层是覆盖画布的 canvas（pointer-events:none）。DOM 交互、SVG 造型、canvas 碎屑。
  • 重组落点 clamp：根据纸片 offsetWidth/Height 限制落点在画布内，避免演示时纸片被拖出裁切（第 1 轮 QA 发现并修复）。
  • 图层重排：指针式 live reorder，锁定「底图 · 描摹稿」不可移动，重排后同步 z 序并触发风掀动画。
  • 对比度：正文 #5A4634 对奶油底 7:1，次级 4.9:1。

验证结果

console errors：0（harness + 交互冒烟多次确认）。prove 断言（真实鼠标拖拽 motion QA）：演示解构时粒子数 221 → 1123 再回落重组；拖拽中途纸片 hidden 变成纸屑云（粒子 702），松开后落点重组可见。
