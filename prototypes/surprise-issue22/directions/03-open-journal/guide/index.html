摊开的手帐本

OPEN JOURNAL · 怎么把它做出来的

收到的 brief

整个 pasteup 界面就是一本摊开的手帐本：左栏是纸张上的手绘目录，右栏是贴纸与色卡，画布是中间的留白页，一切元素都用真实手写字体与胶带、便利贴材质表达。排印拟物能力轴：排印拟物

要 prove 的一件事：一个工具界面可以完全不用「圆角卡片 + 阴影」的 UI 卡片，而用手帐纸面元素（胶带、贴纸、手写、圈注）承载同样的信息架构——排印与拟物达成真正的「手作感」。

签名技法

  • CSS 纸张纤维颗粒：双层 SVG feTurbulence 噪点 data-URI 覆盖，mix-blend-mode: multiply 铺满整本，纸面有纤维感而非纯色。
  • 胶带 / 便利贴 / 撕边拟物：半透明朱红胶带（clip-path 锯齿端 + 透光边缘）、折角便利贴、苔绿纸片撕边票根、页角狗耳折痕。
  • 手写体大标题 + 逐字浮现：Ma Shan Zheng 主标题按字符 staggered 浮现，朱红手绘下划线 SVG stroke-dashoffset 后置描线。
  • 手绘 SVG 箭头 / 圈注 / 涂鸦：批注→枫叶的手绘箭头、选中纸片虚线圈、压花/螺旋/星星边角涂鸦。
  • 纸页阴影层次：书体大投影 + 双页内阴影 + 中缝装订虚线，摊开感来自阴影而非描边。
  • SVG 位移滤镜纸边：枫叶用 feDisplacementMap 让边缘微毛边。
  • 联动微交互：色板着色、纹理改纸面、待办打勾、导出盖「已装订」朱红图章。

真实代码摘录

/* 胶带：clip-path 锯齿端 + 半透明透光边缘 */
.tape {
  background: rgba(192, 57, 43, 0.78);
  clip-path: polygon(
    3% 0, 97% 4px, 100% 100%, 0 96%
  );
  -webkit-mask-image: radial-gradient(
    rgba(0,0,0,0.9), rgba(0,0,0,0.35) 60%
  );
}

资产来源

零外部位图。纸张纤维为 SVG feTurbulence 程序生成；全部拟物元素为 CSS/SVG 手写；字体走 Google Fonts（Ma Shan Zheng / Liu Jian Mao Cao / ZCOOL KuaiLe / Nunito）。

批判循环发现与改动

  • 双页摊开映射 IA：左栏 260 = 目录页（手绘目录/工具/图层 + 回形针），右栏 280 = 色卡与属性便签，画布 = 留白页，中缝 34px 装订线，顶栏 56px 是裁纸 + 骑缝胶带。
  • 纸片叙事：拍立得底图（淡出作底，虚线描摹线）→ 朱红枫叶（描摹产物，带选中圈）→ 苔绿撕边票根（贴胶带）→ 淡紫贴纸。底注「今天描了这片枫叶」把操作写成手帐叙事。
  • 布局 bug：内联 SVG 滤镜占位把书体推下 16px → 修掉后 100vh 恰好填满视口。
  • 对比度：墨褐于纸面 ≈8.6:1，苔绿深底白字 ≈5:1，全 ≥4.5:1。

验证结果

console errors：0；docHeight 900 恰满视口；四族 Google Fonts 全部 loaded；390px 画布置顶无横向溢出；对比度全 ≥4.5:1；交互经 playwright 实测（着色/纹理/待办/图章）；prefers-reduced-motion 降级。
