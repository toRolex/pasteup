# 03 · 摊开的手帐本 OPEN JOURNAL

> **概念一句话**：整个 pasteup 界面就是一本摊开的手帐本——左栏是纸上的手绘目录，右栏是贴纸与色卡，画布是中间的留白页，**信息架构不用一张 UI 卡片，全靠胶带、便利贴、手写与圈注承载**。

一个工具界面可以完全不用「圆角卡片 + 阴影」的 SaaS 组件，而用手帐纸面元素表达同样的顶栏 / 工具 / 图层 / 色板 / 纹理 / 属性信息架构——排印与拟物达成真正的「手作感」。中缝装订线把左页（目录页）与右页（拼贴页）分开，画布上只有撕边纸片、手绘箭头和圈注。

## 技法清单

1. **CSS 纸张纤维颗粒** — 双层 SVG `feTurbulence` 噪点 data-URI 覆盖（高频颗粒 + 低频絮理），`mix-blend-mode: multiply` 铺满整本，纸面有纤维感而非纯色。
2. **胶带 / 便利贴 / 撕边拟物** — 半透明朱红胶带（clip-path 锯齿端 + 透光边缘）、折角便利贴（border 三角折痕）、苔绿纸片撕边票根（clip-path 多边形 + drop-shadow）、页角狗耳折痕。
3. **手写体大标题 + 逐字浮现** — Ma Shan Zheng 主标题/批注按字符 staggered 浮现，朱红手绘下划线 SVG `stroke-dashoffset` 后置描线。
4. **手绘 SVG 箭头 / 圈注 / 涂鸦** — 批注→枫叶的手绘箭头、选中纸片的苔绿虚线圈、压花/螺旋/星星边角涂鸦、竖向裁切边注。
5. **纸页阴影层次** — 书体大投影 + 双页内阴影 + 中缝装订虚线 + 页边描线，摊开感来自阴影而非描边。
6. **SVG 位移滤镜纸边** — 枫叶用 `feDisplacementMap` 让边缘微毛边，像真剪纸。
7. **联动微交互** — 色板点击给枫叶着色（含深色叶脉同步）、纹理点击改苔绿纸片纸面、便签待办可打勾、导出按钮盖「已装订」朱红图章。全部自定义 cubic-bezier easing（`--ease-spring` 用于纸张弹性、`--ease-out` 用于缓入），无裸 linear。

## 关键构建决策

- **双页摊开映射 IA**：左栏 260 = 目录页（手绘目录/工具/图层 + 回形针），右栏 280 = 贴在右页边距的色卡与属性便签，画布 = 留白页；中缝 34px 装订线分隔，顶栏 56px 是一条裁纸 + 一条骑在中缝上的胶带。
- **纸片叙事**：拍立得「照片底图 · 秋日山野」（淡出作底，虚线描摹线）→ 朱红枫叶纸片（描摹产物，带选中圈）→ 苔绿撕边票根（贴一条胶带）→ 淡紫贴纸。底注「今天描了这片枫叶」把工具操作写成了手帐叙事。
- **可访问性**：文本对比度全部 ≥4.5:1（墨褐 #5A4634 于纸面 ≈8.6:1；苔绿深底白字 ≈5:1）；语义化 `header/aside/main/section/button` + aria 标注；`prefers-reduced-motion` 关闭逐字/描线/图章重动效，字符直接显示。
- **响应式**：390px 下画布置顶（`flex order`），随后目录页、中缝变横向、右栏收起成整段；无横向溢出，动效降级可用。
- **零 console errors**；`100vh` 保证书体恰好填满视口（修掉一个内联 SVG 滤镜占位把书体推下 16px 的布局 bug）。
