纸间桌面 · PAPER DESK

how it was built — 指挥收到的 brief 与构建记录

收到的 brief

把 pasteup 画布变成一张真实的三维纸桌：纸片像真彩纸立在暖木桌上，有厚度、有光照、有投影，左栏是一格格的文具盒。实时 3D能力轴：实时 3D

要 prove 的一件事：3D 纸片在真实光照下的立体质感——有厚度、投影落在桌面上，拖动时纸片像被手拿起来，能看出"这是实物纸不是扁平贴图"。

签名技法

  • Three.js r160 实时 3D：木桌 + 背景纸墙 + 纸片 + 文具道具
  • ExtrudeGeometry 纸片厚度：有机轮廓挤出 0.14–0.2 厚度，bevel 收边，侧面材质 0.45x 加深
  • 定向光 + 半球光 + 聚光灯光池：斜向主光软投影（shadow.intensity=0.5）
  • 鼠标视差：相机随指针 lerp，桌面产生景深
  • gsap CustomEase：paperSettle 落桌过冲 / paperLift 拿起 / woodGlide 相机
  • Canvas 程序纹理：木纹（条状 grain + 结节）、纸纤维、水彩晕染、亚麻、素描底图
  • 3D 选中浮签：图层名投影到 3D 空间跟随纸片
  • 拖动拿纸：抬升 0.52 + 微倾 + 跟随指针，松手弹性落桌

相机与厚度是 prove 的关键：初版几乎垂直俯视，纸片侧边不可见。改为斜俯 (0, 5.1, 8.8) + 纸片前移 + 厚度加到 0.2 + 侧面加深 0.45x，侧边带终于清晰可辨。

批判循环发现与改动

  • 投影近黑窟窿：初版阴影 (56,18,5) 像黑窟窿 → shadow.intensity=0.5 + 提高半球光，得到柔和真实纸影。
  • 画面单调：桌面填满画布显单调 → 顶部留纸墙背景条 + 奶油底图照片 + 前景两片纸 + 胶带铅笔高光纸屑，三层景深。
  • 隐蔽 bug：.webgl-fallback 的 display:grid 覆盖了 hidden，fallback 盖住 3D 画布（截图全是 #F3E7D0）→ 加全局 [hidden]{display:none!important}。本轮最关键排查成果。
  • 缓动立场：--ease-snap: cubic-bezier(0.34,1.3,0.5,1) 是刻意的纸感微过冲，服务"实物纸"隐喻。

验证结果

console errors：0（shot harness + 交互回归 + reduced-motion 复跑）。可访问性：对比度 ≥4.5:1、语义化 landmark、prefers-reduced-motion 关重动效、WebGL 不可用时文字回退。响应式：≤700px 左右栏隐藏，画布全屏 + 底部工具条，390px 不塌。
