Fabric v7 每片 pattern+filter 合成到单 canvas 的渲染开销

PROTOTYPE — 一次性代码

50 片纸片（48 顶点扰动闭合多边形）· 2400×1800 场景 · 视口缩放 0.45。方案 A = 每片 Path + Pattern fill（着色预合成在纹理，纹理缩放走 patternTransform）；方案 B = 预合成纸片外观（离屏烘焙 pattern → Image 位图）。 同一布局同一纹理，分别测冷启动首帧 renderAll、拖动热路径（默认 / 协同 setCoords / 强制重建缓存 dirty 三种失效策略）每帧 renderAll、视口平移每帧 renderAll。掉帧线 16.7ms（60fps）。

逐项判定

判定标准（风险 3）：方案 A 拖动热路径 avg 若显著 > 16.7ms（无法维持 60fps）且方案 B 明显更优，则「预合成纸片外观」缓解成立。
